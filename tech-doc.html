1.2 核心目标

  1. API 下单支持显式传入打托策略 palletStrategy（SMART_RECOMMEND_TOSS / WAREHOUSE_AUTO_TOSS）
  2. 支持打托偏好读取 + 偏好降级 + 偏好互斥校验
  3. 支持A+包裹/箱产品装箱（放行已有枚举 CUSTOMER_ALL_SINGLE_SKU_ITEM_PACKING，简化 packageGroupList）
  4. 复用页面下单已有的持久化和仓库同步链路
  5. 页面下单智能混托优化下沉到公共层（TossStrategyHandler），API和页面共用

2.4 业务约束

  1. 装箱+打托可独立传入：可以只传装箱、只传打托、都传、都不传
  2. 偏好补充：未传的策略从偏好配置读取，偏好不全则报错
  3. PTL 出库：最终必须有打托策略（传入或偏好提供），否则报错
  4. 非 PTL 出库：不允许传打托策略（报错提示移除）
  5. 仓库自主装箱 → 打托只能仓库自主打托：互斥约束
  6. 智能推荐打托：palletRuleCode + palletCode + palletStandard + limitL/W/H + limitWeight 必填
  7. 偏好=指定打托 → 降级为仓库自主打托：偏好配置为"客户指定装箱/打托"时，因不支持上传明细，系统按"仓库自主装箱/打托"执行
  8. 偏好=智能打托 + 装箱=仓库自主 → 报错：互斥校验
  9. WAREHOUSE_AUTO_TOSS：传了就走原有仓库自主打托逻辑（已实现），不需要额外参数
  10. 客户白名单：只有白名单客户才走智能推荐打托 + 偏好读取打托的新逻辑，非白名单客户走原逻辑（不触发打托新功能）

T4 — Controller 打托入参格式校验

负责人：张明森 | 文件：OutboundOrderController.java

新增 validatePalletStrategyParams() 方法，包含 5 个校验场景：

/**
 * 打托策略入参校验
 * 注意：装箱和打托可独立传入，不再要求"必须先传packStrategy"
 * PTL出库+不传打托 不在此处报错，留给偏好读取阶段处理
 */
private void validatePalletStrategyParams(OutboundOrderVo orderVo) {
    String palletStrategy = orderVo.getPalletStrategy();
    String exportType = orderVo.getProductInfo().getExportType();
    
    // === 场景1: 非PTL出库 → 不能传打托策略 ===
    if (!LimitAttributeCategoryCode.TRAY_PACKING_LIMITED.equals(exportType)
        && StringUtils.isNotBlank(palletStrategy)) {
        throw new OrderException("当前打包方式不支持传入打托策略，请移除打托策略相关参数");
    }
    
    if (StringUtils.isBlank(palletStrategy)) {
        return; // 不传不校验（PTL出库时后续偏好填充阶段校验）
    }
    
    // === 场景2: 枚举合法性 ===
    TossStrategyEnum strategyEnum = TossStrategyEnum.parse(palletStrategy);
    if (strategyEnum == null || strategyEnum == TossStrategyEnum.CUSTOMER_APPOINT_TOSS) {
        throw new OrderException("不支持的打托策略: " + palletStrategy);
    }
    
    // === 场景3: 仓库自主装箱 → 打托只能仓库自主打托 ===
    if (PackingStrategyEnum.WAREHOUSE_AUTO_PACKING.getCode().equals(orderVo.getPackStrategy())
        && !TossStrategyEnum.WAREHOUSE_AUTO_TOSS.getCode().equals(palletStrategy)) {
        throw new OrderException("装箱策略为「仓库自主装箱」时，打托策略仅支持「仓库自主打托」，请修改打托策略后重试");
    }
    
    // === 场景4: 智能推荐打托 → 必填字段校验 ===
    if (TossStrategyEnum.SMART_RECOMMEND_TOSS == strategyEnum) {
        validateSmartTossRequiredFields(orderVo);
    }
}

private void validateSmartTossRequiredFields(OutboundOrderVo orderVo) {
    // palletRuleCode 必填 + 枚举合法性
    if (StringUtils.isBlank(orderVo.getPalletRuleCode())) {
        throw new OrderException("打托策略为「系统智能推荐打托」时，打托规则(palletRuleCode)为必填项");
    }
    TossRuleEnum ruleEnum = TossRuleEnum.parse(orderVo.getPalletRuleCode());
    if (ruleEnum == null) {
        throw new OrderException("不支持的打托规则: " + orderVo.getPalletRuleCode());
    }
    
    // palletCode 必填
    if (StringUtils.isBlank(orderVo.getPalletCode())) {
        throw new OrderException("打托策略为「系统智能推荐打托」时，托盘规格限制(palletCode)为必填项");
    }
    
    // === 场景5: palletStandard 必填 + 验证编码存在 ===
    if (StringUtils.isBlank(orderVo.getPalletStandard())) {
        throw new OrderException("打托策略为「系统智能推荐打托」时，打托标准(palletStandard)为必填项");
    }
    OutboundPalletStandardGrade grade = palletStandardGradeRepo.findByCode(orderVo.getPalletStandard());
    if (grade == null) {
        throw new OrderException("系统未维护打托等级编码：" + orderVo.getPalletStandard() + "，请维护对应的打托等级信息后再下单");
    }
    
    // 尺寸限制必填
    if (orderVo.getLimitLength() == null || orderVo.getLimitWidth() == null || orderVo.getLimitHeight() == null) {
        throw new OrderException("打托策略为「系统智能推荐打托」时，尺寸限制(limitLength/limitWidth/limitHeight)为必填项");
    }
    if (orderVo.getLimitWeight() == null) {
        throw new OrderException("打托策略为「系统智能推荐打托」时，最大限重(limitWeight)为必填项");
    }
    
    // 超托字段校验
    if (Boolean.TRUE.equals(orderVo.getAllowOversizePallet())) {
        if (orderVo.getOversizeMaxLength() == null || orderVo.getOversizeMaxWidth() == null) {
            throw new OrderException("允许大件超托时，超托最大长/宽(oversizeMaxLength/oversizeMaxWidth)为必填项");
        }
    }
}

验收标准：5 个校验场景全覆盖，错误文案参照页面逻辑。

| API传入情况 | 处理逻辑 | |------------|----------| | 有装箱 + 有打托 | 以API为准，不读偏好 | | 有装箱 + 无打托 | 装箱以API为准，打托读偏好 | | 无装箱 + 有打托 | 打托以API为准，装箱读偏好 | | 无装箱 + 无打托 | 装箱和打托都读偏好 |

偏好读取后处理：

  • 未设置偏好 → 报错："接口和出库装箱打托规则中均未获取打托策略，请在接口/出库装箱打托规则中设置打托策略后重试"
  • 偏好=客户指定装箱/打托 → 降级为仓库自主装箱/打托
  • 命中智能打托偏好 → 取发货国托盘填充尺寸参数（palletCode/limitL/W/H/Weight）
  • 偏好填充后完整性校验（智能打托需完整参数才能调 IPS）
  • 偏好填充后互斥校验（仓库自主装箱+智能打托 → 报错）
/**
 * 偏好配置读取 — 装箱/打托可独立传入，缺哪个补哪个
 * 
 * 实际偏好服务类：outboundConsigneePackageLimitServiceRepo.queryConsigneePackageLimit()
 * 查询参数（共6个）：countryCode, consigneeType, customerCode, limitType, productCategory4, customizeType
 * 返回类型：OutboundConsigneePackageLimitVO（含 defaultStrategy/defaultRule 字段，打托偏好结构与装箱类似）
 * limitType=PALLET 查打托偏好，limitType=PACKING 查装箱偏好
 */
public void buildStrategyByPreference(OutboundOrderVo orderVo) {
    if (!isApiOrPsSource(orderVo)) {
        return;
    }
    
    boolean hasPackStrategy = StringUtils.isNotBlank(orderVo.getPackStrategy());
    boolean hasTossStrategy = StringUtils.isNotBlank(orderVo.getPalletStrategy());
    
    if (hasPackStrategy && hasTossStrategy) {
        return; // 有装箱+有打托 → 不读偏好
    }
    
    // === 装箱偏好 ===
    if (!hasPackStrategy) {
        // 查询参数：countryCode, consigneeType, customerCode, limitType=PACKING, productCategory4, customizeType
        OutboundConsigneePackageLimitVO packConfig = outboundConsigneePackageLimitServiceRepo
            .queryConsigneePackageLimit(
                orderVo.getDispatchWarehouseInfo().getCountryCode(),
                orderVo.getConsigneeType(),
                orderVo.getCustomerInfo().getCustomerCode(),
                "PACKING",
                orderVo.getProductInfo().getWinitProductCategory4(),
                orderVo.getCustomizeType());
        fillPackFromPreference(orderVo, packConfig);
    }
    
    // === 打托偏好（结构与装箱偏好类似，含 defaultStrategy/defaultRule） ===
    if (!hasTossStrategy) {
        OutboundConsigneePackageLimitVO tossConfig = outboundConsigneePackageLimitServiceRepo
            .queryConsigneePackageLimit(
                orderVo.getDispatchWarehouseInfo().getCountryCode(),
                orderVo.getConsigneeType(),
                orderVo.getCustomerInfo().getCustomerCode(),
                "PALLET",
                orderVo.getProductInfo().getWinitProductCategory4(),
                orderVo.getCustomizeType());
        fillTossFromPreference(orderVo, tossConfig);
    }
    
    // === 偏好填充后互斥校验 ===
    validateStrategyMutualExclusion(orderVo);
}

private void fillPackFromPreference(OutboundOrderVo orderVo, OutboundConsigneePackageLimitVO config) {

    }

    // 偏好降级：客户指定装箱 → 仓库自主装箱
    if (PackingStrategyEnum.CUSTOMER_APPOINT_PACKING.getCode().equals(packStrategy)) {
        packStrategy = PackingStrategyEnum.WAREHOUSE_AUTO_PACKING.getCode();
    }
    orderVo.setPackStrategy(packStrategy);
    if (StringUtils.isNotBlank(config.getDefaultRule())) {
        orderVo.setPackRule(config.getDefaultRule());
    }
}

private void fillTossFromPreference(OutboundOrderVo orderVo, OutboundConsigneePackageLimitVO config) {

    }
    String tossStrategy = config.getDefaultStrategy();

/**
 * 打托尺寸限制校验 — 参照 saveCustomTossLimit 已有校验逻辑
 * 
 * 校验依赖：
 * - 托盘规格基础数据：packagingServiceRepo.queryPackagingInfoListByParams(countryCodes, "TRAY")
 * - 数据字典偏移值：PALLET_LIMIT_LENGTH_WIDTH_OFFSET（初始10cm）、PALLET_OVER_LIMIT_OFFSET
 * - 发货国最大限高：outboundConsigneePackageLimitService.queryPalletMaxHeight()
 */
private void validateTossSizeLimit(OutboundOrderVo orderVo) {
    if (!TossStrategyEnum.SMART_RECOMMEND_TOSS.getCode().equals(orderVo.getPalletStrategy())) {
        return;
    }
    
    String countryCode = orderVo.getDispatchWarehouseInfo().getCountryCode();
    String palletCode = orderVo.getPalletCode();
    
    // 校验1: 查托盘规格基础数据，获取托盘标准长宽
    List<PackagingVo> matchedPallets = packagingServiceRepo
        .queryPackagingInfoListByParams(Collections.singletonList(countryCode), "TRAY")
        .stream().filter(vo -> palletCode.equals(vo.getCode())).collect(Collectors.toList());
    if (matchedPallets.isEmpty()) {
        throw new OrderException("托盘规格[" + palletCode + "]在发货国[" + countryCode + "]不存在");
    }
    PackagingVo packagingVo = matchedPallets.get(0);
    BigDecimal palletStandardLength = packagingVo.getInnerLength();
    BigDecimal palletStandardWidth = packagingVo.getInnerWidth();
    
    // 校验2: 限长/限宽 ≤ 托盘标准长宽 + PALLET_LIMIT_LENGTH_WIDTH_OFFSET
    BigDecimal lengthWidthOffset = getDictValue("PALLET_LIMIT_LENGTH_WIDTH_OFFSET");
    BigDecimal maxAllowedLength = palletStandardLength.add(lengthWidthOffset);
    BigDecimal maxAllowedWidth = palletStandardWidth.add(lengthWidthOffset);
    if (orderVo.getLimitLength().compareTo(maxAllowedLength) > 0) {
        throw new OrderException("托盘最大限长超出最大限制" + maxAllowedLength + "，请修改");
    }
    if (orderVo.getLimitWidth().compareTo(maxAllowedWidth) > 0) {
        throw new OrderException("托盘最大限宽超出最大限制" + maxAllowedWidth + "，请修改");
    }
    
    // 校验3: 限高 ≤ 发货国最大限高
    OutboundConsigneePackageLimitQueryCommand heightQuery = new OutboundConsigneePackageLimitQueryCommand();
    heightQuery.setCountryCodeList(Collections.singletonList(countryCode));
    heightQuery.setConsigneeType(orderVo.getConsigneeType());
    PalletMaxHeightRespVO heightResp = outboundConsigneePackageLimitService.queryPalletMaxHeight(heightQuery);
    if (heightResp != null && heightResp.getMaxHeight() != null && orderVo.getLimitHeight() != null) {
        if (orderVo.getLimitHeight().compareTo(new BigDecimal(heightResp.getMaxHeight())) > 0) {
            throw new OrderException("托盘最大限高不能超过" + heightResp.getMaxHeight() + "cm，请修改");
        }
    }
    
    // 校验4: 超托校验
    if (Boolean.TRUE.equals(orderVo.getAllowOversizePallet())) {
        BigDecimal overLimitOffset = getDictValue("PALLET_OVER_LIMIT_OFFSET");
        // 超托限长/宽 必须 > 正常限长/宽
        if (orderVo.getOversizeMaxLength() != null && orderVo.getLimitLength() != null
            && orderVo.getOversizeMaxLength().compareTo(orderVo.getLimitLength()) <= 0) {
            throw new OrderException("超托最大限长必须大于正常限长");
        }
        if (orderVo.getOversizeMaxWidth() != null && orderVo.getLimitWidth() != null
            && orderVo.getOversizeMaxWidth().compareTo(orderVo.getLimitWidth()) <= 0) {
            throw new OrderException("超托最大限宽必须大于正常限宽");
        }
        // 超托限长/宽 ≤ 正常限长/宽 + PALLET_OVER_LIMIT_OFFSET
        if (orderVo.getOversizeMaxLength() != null && orderVo.getLimitLength() != null) {
            BigDecimal overPalletMaxLength = orderVo.getLimitLength().add(overLimitOffset);
            if (orderVo.getOversizeMaxLength().compareTo(overPalletMaxLength) > 0) {
                throw new OrderException("超托限长不能超过" + overPalletMaxLength + "cm，请修改");
            }
        }
        if (orderVo.getOversizeMaxWidth() != null && orderVo.getLimitWidth() != null) {
            BigDecimal overPalletMaxWidth = orderVo.getLimitWidth().add(overLimitOffset);
            if (orderVo.getOversizeMaxWidth().compareTo(overPalletMaxWidth) > 0) {
                throw new OrderException("超托限宽不能超过" + overPalletMaxWidth + "cm，请修改");
            }
        }
    }
}

public void optimizeAndGenerateResult(PackingStrategyCommand command) {
    if (TossRuleEnum.SMART_OPTIMAL_MIXED_TOSS.getCode().equals(command.getRule())) {
        command = doOptimizeSmartMixedToss(command);
    }
    generatePackingResult(command);
}

/**
 * 智能混托优化：两种规则试算比较，取托盘数少的方案
 */
private PackingStrategyCommand doOptimizeSmartMixedToss(PackingStrategyCommand command) {
    PackingStrategyCommand priorityCommand = command.clone();
    priorityCommand.setRule(TossRuleEnum.SMART_PRIORITY_SAME_PACKAGE_TOSS.getCode());
    
    List<TossResultVo> mixedResults = calculateToss(command);
    List<TossResultVo> priorityResults = calculateToss(priorityCommand);
    
    int mixedPalletCount = mixedResults.size();
    int priorityPalletCount = priorityResults.size();
    
    if (mixedPalletCount > priorityPalletCount) {
        logger.info("智能混托优化：混托托盘数{}多于优先同类包裹打托{}，自动切换规则",
            mixedPalletCount, priorityPalletCount);
        return priorityCommand;
    }
    return command;
}

/**
 * 打托试算（只计算不持久化）
 * 复用 doGeneratePackingResult() 前半段：buildStrategyPackParam → IPS → buildTossContainer
 * 跳过 flushTaskNo
 */
public List<TossResultVo> calculateToss(PackingStrategyCommand command) {
    BoxStrategyParam strategyParam = buildStrategyPackParam(command);
    strategyParam.setBoxStrategyType(BoxStrategyType.TOSS);
    String taskNo = getPackingTaskNo(command);
    strategyParam.setTaskNo(taskNo);
    PackResultVo ipsResult = packagingGoodsService.packV2(strategyParam);
    return buildTossContainer(ipsResult, command);
}

页面下单兼容：页面如果也需要混托优化，只需将调用入口改为 optimizeAndGenerateResult(command) 即可，原有非混托场景不受影响。

验收标准：混托规则时两种规则都打、比较取优；非混托规则直接打；页面下单不受影响。

T15 — 打托标准等级保存

负责人：邹梁琦 | 文件：PackStrategyApiExecFacade.java (VAS 属性构建)

背景：入参 palletStandard 是打托标准规则编码（即 DC 系统 dc_wh_outbound_pallet_standard_grade 表的 UNIQUE_CODE）。一个规则对应一个打托等级，打托等级有名称、编码(gradeCode)和版本号。

现有机制（参考 VasFeeConvert.java / OutboundOrderCalculateVoConvert.java）：

  • VAS 属性 PALLET_STANDARD_GRADE_CODE 存的是 uniqueCode（不是 gradeCode）
  • VAS 属性 PALLET_STANDARD_GRADE_VERSION 存的是版本号
  • 运行时通过 PalletStandardGradeHelper.getGradeCode(null, uniqueCode, version) 调 DC SPI (PalletStandardGradeService.getBriefByUniqueCode()) 实时获取 gradeCode
  • gradeCode 在 buildStrategyPackParam() 阶段从 command 取值传给 IPS

已有工具类：com.winit.oms.commons.PalletStandardGradeHelper

  • getGradeCode(id, uniqueCode, version) → 基于 uniqueCode + version 从 DC SPI 获取 gradeCode
  • getGradeName(id, uniqueCode, version) → 获取 gradeName

API 下单时写入逻辑：

// 在 buildPackStrategyAppointPackingVas() 关联 OSF8V1727 时同步写入
if (StringUtils.isNotBlank(orderVo.getPalletStandard())) {
    String uniqueCode = orderVo.getPalletStandard();
    
    // 1. 调 DC SPI 获取最新版本号
    PalletStandardGradeService dcService = SpringContextHolder.getBean(PalletStandardGradeService.class);
    QueryPalletStandardGradeCommand queryCmd = new QueryPalletStandardGradeCommand();
    queryCmd.setUniqueCode(uniqueCode);
    queryCmd.setVersion(null); // null 取最新版本
    PalletStandardGradeBriefVO briefVO = dcService.getBriefByUniqueCode(queryCmd);
    
    String version = briefVO != null ? briefVO.getVersion() : null;
    String gradeCode = briefVO != null ? briefVO.getGradeCode() : null;
    
    // 2. 写 VAS 扩展属性
    // PALLET_STANDARD_GRADE_CODE = uniqueCode（与页面逻辑一致）
    addVasAttribute(vasDTO, newAttributeVos, OrderVasExpandInfoConstants.PALLET_STANDARD_GRADE_CODE, uniqueCode);
    // PALLET_STANDARD_GRADE_VERSION = DC 返回的最新版本号
    if (StringUtils.isNotBlank(version)) {
        addVasAttribute(vasDTO, newAttributeVos, OrderVasExpandInfoConstants.PALLET_STANDARD_GRADE_VERSION, version);
    }
    // PALLET_STANDARD_GRADE_VERSION_FLAG = "Y" （新版本标记）
    addVasAttribute(vasDTO, newAttributeVos, OrderVasExpandInfoConstants.PALLET_STANDARD_GRADE_VERSION_FLAG, "Y");
    
    // 3. PALLET_STANDARD_CONFIG = 打托标准编码（palletStandard 原值）
    addVasAttribute(vasDTO, newAttributeVos, OrderVasExpandInfoConstants.PALLET_STANDARD_CONFIG, uniqueCode);
    
    // 4. 设置 command 的 palletGradeCode/palletGradeVersion，供后续 buildStrategyPackParam() 透传 IPS
    command.setPalletGradeCode(gradeCode);
    command.setPalletGradeVersion(version);
}
